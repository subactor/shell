Subactor Shell

Persistent terminal orchestration for Subactor — IntentIR routing, governed Control integration, sessions, Vault references and ACP stdio.

Installing and running Subactor Shell

Run the following on Mac or Linux:

curl -fsSL https://subactor.github.io/shell/install.sh | sh

Run the following on Windows:

powershell -ExecutionPolicy ByPass -c "irm https://subactor.github.io/shell/install.ps1 | iex"

The standalone installers download release metadata from subactor.github.io/shell by default and fall back to GitHub Releases when metadata or assets are unavailable. To force GitHub Releases: 

curl -fsSL https://subactor.github.io/shell/install.sh | SUBACTOR_SHELL_INSTALLER_USE_GITHUB_IO=false sh
$env:SUBACTOR_SHELL_INSTALLER_USE_GITHUB_IO='false'; irm https://subactor.github.io/shell/install.ps1 | iex

After install

subactor-shell init
subactor-shell chat

Requires Python 3.11+. The installer creates an isolated virtualenv under ~/.local/share/subactor-shell/venv and links subactor-shell into ~/.local/bin.
